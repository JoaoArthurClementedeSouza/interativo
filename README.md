## 📌 Sobre o projeto

O Cadastro de Alunos é um projeto desenvolvido para praticar
conceitos de desenvolvimento web. A página apresenta um formulário para
inserir o nome e a nota de um aluno, além de uma área para visualizar e
pesquisar os registros.

A interface foi estruturada com HTML, enquanto os arquivos CSS e
JavaScript são responsáveis pela apresentação visual e pelas interações
da aplicação.

## 🖥️ Prévia do projeto

A página principal contém:

-   Formulário para informar nome e nota;
-   Campo de pesquisa de alunos;
-   Tabela com as colunas **Nome**, **Média** e **Situação**;
-   Mensagens para orientar o usuário durante o uso.

## ✨ Funcionalidades da interface

-   **Cadastro de alunos:** formulário com campos para nome e nota.
-   **Validação:** o formulário utiliza JavaScript para validar os
campos.
-   **Pesquisa:** campo para localizar alunos pelo nome.
-   **Tabela:** exibição dos registros nas colunas Nome, Média e
Situação.
-   **Remoção:** a interface orienta que um aluno pode ser removido com
dois cliques sobre seu registro.

## 🧰 Tecnologias utilizadas


| Tecnologia | Aplicação no projeto |

| HTML5 | Estrutura da página, formulário e tabela |

## ▶️ Como executar

1.  Faça o download ou clone este repositório.
2.  Abra a pasta do projeto no Visual Studio Code.
3.  Confira se `index.html`, `estilo.css` e `script.js` estão na mesma
pasta.
4.  Abra o arquivo `index.html` em um navegador.
5.  Utilize o formulário para experimentar a aplicação.
