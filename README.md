# Sistema de Cadastro de Alunos

## Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema web para cadastro e gerenciamento de alunos, permitindo registrar nomes, notas e acompanhar a situação de cada estudante.

O objetivo é desenvolver uma aplicação simples e funcional, utilizando tecnologias de desenvolvimento web.

## Funcionalidades

- Cadastro de alunos.
- Registro de notas.
- Validação dos campos de cadastro.
- Pesquisa de alunos pelo nome.
- Exibição dos alunos em uma tabela.
- Visualização da média e situação dos alunos.
- Remoção de alunos da turma por meio de dois cliques sobre o registro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se todos os arquivos estão na mesma pasta.
4. Abra o arquivo `index.html` no navegador.
5. Utilize o formulário para cadastrar e consultar alunos.
